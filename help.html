Documentation

This tool converts text written in a specific syntax into interactive HTML quizzes or static LaTeX documents.

File Structure & Metadata

A file must begin with a header block enclosed in ---. The title variable is strictly required. Any additional custom fields provided here will be output solely onto the LaTeX cover page.

---
title: Introduction to Physics
Instructor: Dr. Smith
Date: October 23, 2025
---
...questions start here

Questions

Questions must be separated by ---.

  • Multiple-Choice: Write the question immediately after the #Q tag. Mark the correct answer with - [x] and incorrect answers with - [ ]. Provide an explanation under the #A tag.
  • Open-Ended: Omit the multiple choice options. The interactive HTML output will hide the #A block behind a toggle button.
  • Scoring (LaTeX only): Append a colon and a number to the question marker (e.g., #Q:5) to display a point indicator in the PDF output.
#Q
What is the capital of France?
- [x] Paris
- [ ] London
- [ ] Berlin
#A
Paris is the capital of France.

Formatting

  • Wrap text in double asterisks for bold: **bold text**
  • Wrap text in single asterisks for italic: *italic text*

Mathematics

The converter integrates MathJax formatting for equations.

  • Inline math: Wrap the expression in single dollar signs: $E=mc^2$.
  • Display math: Wrap the expression in double dollar signs: $$ a^2 + b^2 = c^2 $$.

Material Blocks

You can embed distinct elements inside a question (after the #Q tag) by using bracketed block syntaxes.

Text Context: [material]

[material]
Read this passage before answering the question.
[/material]

Code: [code:language]

Displays a monospaced code block with syntax language specified.

[code:javascript]
function test() { return true; }
[/code]

Quotes: [quote]

Renders a blockquote. Optionally provide an attribution by starting a line with Source: or Author:.

[quote]
To be or not to be.
Author: William Shakespeare
[/quote]

Tables: [table]

Construct tables using pipes (|) and a separator line (|---|) between the header and the body data.

[table]
| Item | Price |
|---|---|
| Apple | $1 |
| Banana | $2 |
[/table]

Outputs

  • Generate HTML: Produces a standalone, interactive HTML file. Works offline. Includes a theme toggle.
  • Generate LaTeX: Produces a .tex source file to compile into a PDF. Cover page metadata and point values are included. Options exist to generate questions only or include an answer key.
